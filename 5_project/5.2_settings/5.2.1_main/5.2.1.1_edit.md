#### 5.2.1.1 Изменение основных настроек проекта

[Доступ к функции ограничен](../../../10_roles_&_access/10.2_access.md).

**Для внесения изменений** в основные данные проекта требуется:  

1. Войти в пространство, к которому принадлежит  проект, выбрав его из списка [доступных пространств](../../../4_workspace/4.1_me_workspaces.md) на [панели меню](../../../3_menu/3_menu.md)  
2. В разделе "**Проекты**" на панели меню нажать на значок ![button_3points](/imgs/button_3points.jpg) рядом с названием изменяемого проекта.  
3. Выбрать в открывшемся списке пункт **"Настройки"**.  

   ![project-3](/imgs/project-3.jpg)

Откроется раздел [Основные](5.2.1_main.md) на странице "Настройки проекта".

B строках верхней части страницы есть возможность:  

![5.2-1](/imgs/5.2-1.jpg)

- добавить **"Аватар проекта"** или изменить значок **"Эмодзи"**.
- изменить название (**"Имя"**) проекта;
- создать или изменить **"Описание"** ;
- изменить **"Идентификатор"** проекта;
- изменить степень открытости проекта - **"Приватность"**. Публичные проекты видны всем пользователям пространства;
- запретить/разрешить удаление задач с помощью чекбокса **"Разрешить удаление задач"**.
- разрешить участникам прикреплять вложения к любым задачам проекта с помощью переключателя **"Разрешить всем прикреплять вложения"**. По умолчанию участник может прикреплять вложения только к задачам, где он автор или исполнитель. На гостей настройка не распространяется, на удаление вложений не влияет;
- разрешить участникам изменять [дополнительные параметры](../5.2.7_additional_param.md) в любых задачах проекта с помощью переключателя **"Разрешить всем редактировать дополнительные параметры"**. По умолчанию участник может изменять дополнительные параметры только в задачах, где он автор или исполнитель. На гостей настройка не распространяется, параметры с видимостью "только администраторы" по-прежнему доступны только администраторам.


После внесения изменений требуется нажать на кнопку ![button_save](/imgs/button_save.jpg) в правой части страницы.
